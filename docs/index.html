部署示例

基础部署

$ chmod +x run.sh
$ ./run.sh \
  --domain your_domain.com \
  --reverse_proxy_server http://127.0.0.1 \
  --cf_token your_cloudflare_token

自定义镜像仓库

$ ./run.sh \
  --services hub,ui,caddy \
  --domain your_domain.com \
  --reverse_proxy_server http://127.0.0.1 \
  --cf_token your_cloudflare_token

高级配置

$ ./run.sh \
  --update_yml true \
  --proxy_ttl 168h \
  --health_enabled true \
  --health_interval 10s \
  --storage_upload_enabled true

常见问题

关于 DockerProxyOneKey 的常见疑问解答

这个项目解决了什么问题？

由于许多Docker镜像仓库位于国外，国内用户下载镜像时速度较慢。虽然有一些免费代理服务，但通常需要白名单审核，流程较为繁琐。本项目通过一键脚本在自己服务器上部署镜像加速服务，无需等待审核，即开即用。

需要什么样的服务器？

需要一台可以访问国外Docker镜像仓库的服务器（俗称"魔法服务器"），并已安装Docker。脚本会自动处理其他依赖的安装和配置。

如何获取 Cloudflare API Token？

登录 Cloudflare 后，访问 API Token 页面创建新令牌，选择 "Zone: DNS: Edit" 权限即可。同时需要在域名管理中配置DNS记录，将域名指向你的服务器IP地址。

支持哪些 Docker 镜像仓库？

支持多种主流镜像仓库，包括 Docker Hub、Kubernetes (K8s)、Quay、GitHub Container Registry (Ghcr)、Microsoft Container Registry (Mcr)、Elastic 等等。

如何配置安全验证？

如果需要htpasswd验证，可以创建 .cache/htpasswd 文件并配置用户密码。可以使用在线htpasswd生成器创建密码文件，脚本会自动加载验证配置。
